# متن معرفی (بازارهای ایرانی)

**نام:** PingScore — سنجش کیفیت اتصال

**توضیح کوتاه (۸۰ کاراکتر):** ببینید اتصال فعلی‌تان برای کار، ویدیو و تماس چقدر به‌درد می‌خورد.

**توضیح کامل:**
اینترنت‌تان وصل است، ولی واقعاً کارتان راه می‌افتد؟ PingScore در چند ثانیه کیفیت اتصال فعلی را می‌سنجد و برای سه کاربرد نمره‌ی ۰ تا ۱۰۰ می‌دهد:

• کار با هوش مصنوعی
• ویدیو و دانلود
• چت و تماس

امکانات:
• سنجش ping، jitter و packet loss
• تست سرعت دانلود و آپلود در دو حالت «سریع» و «کامل»
• بررسی باز شدن سایت‌های دلخواه شما و سلامت DNS
• اجرای خودکار تست با تغییر اتصال
• ذخیره‌ی تاریخچه، نام‌گذاری اتصال‌ها، نمودار و مقایسه‌ی «اتصال فعلی» با «اتصال قبلی» و «اتصال پایه»
• پایش دوره‌ای اختیاری و کم‌مصرف
• خروجی متنی نتیجه برای اشتراک‌گذاری

حریم خصوصی: بدون ثبت‌نام، بدون تبلیغ و بدون ارسال داده؛ همه‌چیز فقط روی گوشی شما می‌ماند.
مجوزها: فقط اینترنت و وضعیت شبکه.

**کلیدواژه‌ها:** سرعت اینترنت، تست سرعت، پینگ، کیفیت اتصال، DNS، تاریخچه‌ی شبکه
