# PingScore — مراحل ۲ تا ۶

## ساخت
Android Studio (Koala یا جدیدتر)، JDK 17، Gradle wrapper را با «Sync» بسازید. فونت را طبق `app/src/main/assets/fonts/README.txt` اضافه کنید.
تست واحد: `./gradlew :app:testDebugUnitTest`

## ساختار
- `diag/` : PingTester, SpeedTester, SiteChecker, DnsChecker, TestRunner, پیش‌فرض‌ها (`Config.kt`)
- `score/` : `ScoreWeights.kt` (همه‌ی وزن‌ها و آستانه‌ها)، `ScoreEngine.kt`
- `data/` : Room، مخزن، تنظیمات، `TestPipeline` (تست ← نمره ← ذخیره)
- `work/` : WorkManager
- `ui/` : صفحه‌ها (اصلی، نتیجه، تاریخچه، مقایسه، تنظیمات)

## محدودیت‌های پس‌زمینه در اندروید
- کمترین بازه‌ی کار دوره‌ای ۱۵ دقیقه است؛ زمان دقیق را سیستم تعیین می‌کند.
- Doze و App Standby اجرا را عقب می‌اندازند؛ Battery Saver ممکن است کارها را متوقف کند.
- قید «باتری کم نباشد» و قید شبکه (Wi-Fi/نامحدود یا هر شبکه) روی کار گذاشته شده است.
- برای کاهش مصرف: پایش فقط حالت سریع است و پیش‌فرض بدون تست سرعت؛ سرعت فقط با انتخاب کاربر.
- WorkManager مجوزهای WAKE_LOCK, RECEIVE_BOOT_COMPLETED, FOREGROUND_SERVICE را اضافه می‌کند که برای رعایت «فقط دو مجوز» از manifest حذف شده‌اند؛ پس بعد از ریبوت، پایش با اولین اجرای برنامه دوباره برنامه‌ریزی می‌شود.

## نکته‌های اندازه‌گیری
- آپلود فقط روی Cloudflare تعریف شده (CDN های دیگر معمولاً نقطه‌ی آپلود عمومی ندارند). در `Defaults.speedTargets` می‌شود مقصد اضافه کرد.
- بعضی اتصال‌ها پاسخ TCP را محلی می‌دهند و ping را کمتر از واقع نشان می‌دهند؛ تست HTTP و سرعت این را متعادل می‌کند.
- «نشت DNS» یک تشخیص احتمالی (heuristic) است نه قطعی.
- نمره‌ها برآوردی‌اند؛ برای مقایسه‌ی منصفانه، تست‌ها را در یک حالت (سریع/کامل) بگیرید.
